# Entorno de entrenamiento - Prevencion de Caidas y Riesgos en Escaleras
#
# Reproducible con:
#   python3 -m venv venv
#   ./venv/bin/python -m pip install -r requirements.txt
#
# NOTA SOBRE LA GPU: la RTX 5050 es Blackwell (sm_120), que requiere wheels
# de PyTorch compilados con CUDA 12.8. Por eso torch y torchvision se
# fijan a la build +cu128, NO a la de cuda por defecto. Si se omite este
# indice, torch cae a sm < 120 y falla al ejecutar en la GPU.
#
#   ./venv/bin/pip install --index-url https://download.pytorch.org/whl/cu128 \
#       torch==2.11.0+cu128 torchvision==0.26.0+cu128
#
# PARA CPU (sin GPU NVIDIA): usar setup.sh que detecta hardware automáticamente,
# o instalar manualmente:
#   ./venv/bin/pip install --index-url https://download.pytorch.org/whl/cpu \
#       "torch==2.6.0+cpu" "torchvision==0.21.0+cpu"
#   ./venv/bin/pip install onnxruntime==1.30.0  # CPU instead of onnxruntime-gpu
# (No instalar nvidia-cu12* packages en modo CPU)
